## Projects

| Project | Issues | What We're Solving |
|---|---|---|
| **[Terminal-Agent](https://github.com/PicadoLabs/terminal-agent)** - Autonomous AI coding agent for the terminal | [Issues](https://github.com/PicadoLabs/terminal-agent/issues) | Running AI coding agents safely and reliably in real terminals - verify-first execution, sandboxing, and recovery so agents can act without unchecked risk. |
| **[Agent-Bench](https://github.com/PicadoLabs/agent-bench)** - Benchmarking platform for AI coding agents | [Issues](https://github.com/PicadoLabs/agent-bench/issues) | Lack of standardized, reproducible ways to evaluate coding agents across providers — consistent tasks, sandboxed runs, and comparable scoring. |
| **[AI-Model-Router](https://github.com/PicadoLabs/ai-model-router)** - Intelligent routing across AI models | [Issues](https://github.com/PicadoLabs/ai-model-router/issues) | Picking the right model for each request — cost- and latency-aware, capability-based routing with fallback and explainable decisions. |
